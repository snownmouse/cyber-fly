果蝇脑启发的闭环智能

一只果蝇如何在约 100 毫秒内"感知危险 → 中枢决策 → 转身逃走"？本项目以 2024 年发表的果蝇全脑连接组为灵感， 用一套"边缘感知执行 + 云端连接组大脑"的闭环架构，把昆虫的神经原理工程化为可演示的系统。下面用一页讲清：核心原理、系统流程、参考项目与文献。

连接组学 · 分层脑模型 · 闭环感觉运动控制 · 果蝇全脑连接组（Nature 2024）

核心原理

支撑这套系统的六个神经科学 / 控制理论概念（均为公开科学原理，非逐神经元复刻）。

连接组学

脑是一张"接线图"

连接组学研究神经元之间的连接（突触）。2024 年果蝇全脑连接组给出约 13.9 万神经元、约 5000 万突触的完整接线图；系统以"功能区 + 行为指令"做功能级近似。

分层脑模型

外周—脑干—中枢

生物上感觉与运动在外周/低级中枢，复杂决策在高级中枢。系统把采集与执行下沉到边缘端（脑干/脊髓层），把决策放到云端（中枢），各司其职。

命令神经元

一小群细胞决定"逃不逃"

生物中少数命令神经元把"逃逸/转向"等离散决策变成下行指令驱动肌肉。系统中对应为行为指令信号（逃逸/转向/梳理/进食）。

发放率 + 低通

用"放电频率"表达活动

神经活动常用放电频率（发放率）编码；再用简单低通（状态估计）平滑传感噪声与行为抖动，得到稳定的激活水平。

闭环控制

感知→动作→反馈→再感知

真正的智能是闭环的：中枢下达指令，身体执行，环境变化再被感知。系统的下行指令驱动执行器，完成"身体—环境"闭环。

生物原型

中央复合体 / 蘑菇体

果蝇的中央复合体主管导航定向，蘑菇体主管学习记忆——是"行为选择"与"记忆"的生物原型，作为功能区设计的灵感来源。

系统如何工作（闭环流程图）

从"外周感觉"到"中枢决策"再到"网页可视化"，并用下行指令闭合回到执行器。蓝线为闭环。

外周感觉 边缘控制器（脑干/脊髓层） 网络中继 连接组大脑（中枢） 感觉/运动诊断 可视化看板 蓝线 = 闭环（下行指令 / 行为反馈）

参考项目（真实存在、可对标）

这些公开项目与成果，是"用工程复现昆虫神经原理"这一思路的现实依据。

连接组平台

FlyWire 全脑连接组

Princeton（Seung 组）+ Janelia（Murthy、Bock）联合重建的果蝇全脑连接组平台，可交互浏览约 13.9 万神经元接线——本系统"连接组大脑"概念的直接来源。

部分连接组

hemibrain

Janelia（Scheffer 等，2020）里程碑式的果蝇中枢脑部分连接组（约 2.5 万神经元），neuPrint 可在线浏览，是连接组研究的工程基础。

仿生飞行

DelFly Nimble

TU Delft MAVLab 的果蝇启发扑翼机器人，研究果蝇"逃逸机动"（倾斜转弯）的敏捷飞行，证明昆虫逃逸控制可被工程复现。

微飞行机器人

RoboBee

Harvard（Wood 组）的昆虫尺度微飞行机器人（约 80 mg，Science 2013），微尺度飞行与驱动的代表性成果。

脑—体闭环

DragonflEye

Draper + HHMI 用光遗传学直接驱动活体蜻蜓飞行，是"脑—机—生物体"闭环控制的极端例子。

数据 / 工具

neuPrint · VFB · FlyBase

连接组浏览器与果蝇神经解剖 / 基因数据库，做生物映射与原理查证时的权威公开来源。

GitHub · 本系统引擎

flywire-fly-lab（suifei/flywire-fly-lab）

对 FlyWire 2024 果蝇全脑连接组 的工程复现（Shiu/Sterne 全脑 LIF 模型）：含实时仿真引擎 dodge/brain.js、子回路提取、刺激编码与读出。本系统云端"连接组大脑"即运行其 v4 子回路（6,296 神经元 / 475,562 突触）——真实连接组接线，非手写近似。
