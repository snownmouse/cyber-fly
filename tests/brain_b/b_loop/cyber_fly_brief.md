# 果蝇脑 · cyber_fly 项目梳理（视频脚本素材）

> 用途：视频脚本的"底稿"。基础内容一次性串清楚，录制时直接照这个逻辑讲。

---

## 1. 一句话讲清楚这是什么
把一只果蝇的"脑"搬进云服务器，用一块 ESP32 开发板当它的"身体"——真实传感器喂数据、真实电机做动作，跑起一个**真实的"感知 → 思考 → 行动"闭环**。

## 2. 生物映射（整个项目的核心创意）
| 真实生物结构 | 项目里的对应角色 | 说明 |
|---|---|---|
| 感觉器官（耳 / 前庭） | 麦克风 + BMI270 IMU 传感器 | 收声音（听觉）、收加速度（姿态/侧向） |
| 脑干 / 脊髓（I/O 网关） | **ESP32 板子** | 收感官、发指令、做低级信号调理；**不是小脑**（小脑管精细协调，云端才做"思考"） |
| 大脑 / 连接组 | **云端连接组仿真** | 38 神经组 / 9 大功能区，算发放率、出行为 |
| 运动神经 / 肌肉 | 电机、振翅、转向执行 | 把脑指令变成动作 |

**一句话记忆点**：云端是"脑"，ESP32 是"脑干+脊髓"，传感器是"感官"，电机是"肌肉"。

## 3. 技术架构（1 块板 + 4 个云端进程）
- **板子 ESP32（固件 cyber_fly）**：麦克风 + IMU，经手机热点（2.4G，叫 your-ssid）上行 UDP 连云。
- **relay.js**：UDP 中转枢纽（端口 33333），**用同一个 socket 做双向转发**（这里踩过"只单向通"的坑，已修）。
- **stage1_loop.js**：连接组大脑仿真 + 影子脑读发放率 + HTTP `/api`（33338，只绑回环，不暴露公网）。
- **fly_watch2.js**：诊断转发（33336），算音频判定（rms/jo/verdict），**纯 UDP 无 HTTP，闭环关键，不动它**。
- **fly_dashboard.js**：8080 网页 + 代理 `/api`，渲染指标卡 / 曲线 / 38 组活跃度 / **脑区神经图** / **数据汇报**。

## 4. 数据流（闭环怎么转）
```
感知(板: 麦克风+IMU)
   → 手机热点 UDP
   → relay 中转
   → 云端脑计算(stage1_loop: 38组/9区)
   → 行为指令(relay 回传)
   → 板执行(电机/振翅/转向)
   → 真实环境变化
   → 再感知（闭环）
```
观测随时可读：网页看板（8080）+ 音频诊断（fly_watch2）。

## 5. 参考论文（讲出处，立得住）
- **FlyWire 联盟，Nature 2024-10**：画出成体雌果蝇**完整连接组**——约 **13.9 万神经元、5450 万突触**，史上最大 connectome（9 篇论文同刊）。
- **Shiu, Sterne et al., *Nature* 634:210–219 (2024)**：《A Drosophila computational brain model reveals sensorimotor processing》——用**泄漏积分放电（LIF）模型**，只靠"突触连接 + 神经递质类型"，就复现了**完整的感觉→运动转换**（论文具体验证了取食、梳理两类行为）。
- **我们的项目 = 同一科学原理的功能化落地**：感官输入 → 连接组计算 → 运动输出。论文还指出果蝇脑的 SEZ 区"接收绝大部分输入、发出绝大部分到运动神经元的输出"，正好对应本项目"数据进、行为出"的架构。

## 6. 关键数字（视频里可以念）
- 真实连接组：**~14 万神经元 / 5450 万突触**
- 本项目模型：**38 神经组 / 9 功能大区**
- 闭环：**20 Hz**，渲染 **~29 fps**
- 云端往返：**~52 ms**（比很多生物环路还快）
- 4 个云端进程；公网看板 **8080**

## 7. 诚实的边界（措辞要准，别被挑刺）
- 是"**连接组启发的脑模型**"，不是 14 万神经元的逐神经元仿真——这是功能化抽象，做演示完全够用。
- 严格实时反射（脊髓级）留在 ESP32 本地做，高层决策在云端——和生物学"脊髓反射 vs 皮层决策"的分工一致，逻辑自洽。

## 8. 怎么一步步搭出来的（build 顺序）
1. **板端固件 cyber_fly**（ESP32）：接麦克风 + IMU，经热点连云，UDP 收发。
2. **云端大脑 stage1_loop**：连接组仿真 + 影子脑读发放率 + 只读 `/api`。
3. **relay.js**：UDP 中转枢纽（修了"同 socket 双向"的坑，否则板子只发不收）。
4. **fly_watch2**：诊断转发，算音频判定（闭环关键，无 HTTP）。
5. **fly_dashboard**：8080 网页看板（本次重做：脑区神经图 + 数据汇报）。
6. **真机闭环打通（任务 C）**：板子 ↔ 云 20 Hz 双向，屏上每一帧都由真实脑输出驱动。

## 9. 建议视频结构（串场）
1. **开场**：一只果蝇，和它那 14 万神经元的脑（抛出 Nature 2024）。
2. **我们想干什么**：把"脑"拆出来放到云上，再给它一个身体。
3. **三件套**：传感器 = 感官、ESP32 = 脑干/脊髓、云端 = 脑。
4. **闭环演示**：放歌 → 脑算 → 振翅/逃逸；动板子 → 转向。
5. **看板**：脑区图哪块亮、数据汇报念什么。
6. **收尾**：这是连接组启发的真实闭环；下一步可做完整仿真 / 加斜向飞行。
