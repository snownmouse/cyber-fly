**交叉验证**：本仓库自述"real brain runs one fly at **1.18×** real time"（15,055 神经元），
我们实测 0.96–1.00× —— 差 ~1.2 倍，正好是 M1 Pro 单核相对 EPYC 2.0GHz 单核的差距。**两个独立测量互证。**

### 引擎参数（`results/dodge/subcircuit*.json` 的 `meta.params`，全版本一致）

```
dt   = 0.1 ms     v0   = -52 mV    vrst = -52 mV    vth  = -45 mV
t_mbr= 20 ms      tau  = 5 ms      t_rfc= 2.2 ms    t_dly= 1.8 ms
w_syn= 0.275      f_poi= 250 Hz
```

**注意 `t_dly = 1.8 ms`** —— 上一轮我提的"把 dt 粗化到 20 ms 来省算力"是**错的**：
1.8 ms 突触延迟在 20 ms 步长下会被 round 成 0 步，整套延迟结构直接消失。
**所幸不需要粗化 —— 原生 dt = 0.1 ms 就已经跑得动。**

### 引擎算法（`dodge/brain.js`，18 KB，Node/浏览器通用）

- 神经元：**LIF，线性 ODE 精确解** `v ← v0 + (v−v0)·a + g·c`，`g ← g·b`（`a=exp(−dt/t_mbr)`、`b=exp(−dt/tau)`）
- 发放：`v > −45 mV` → 重置 `v=−52`、`g=0`、不应期 2.2 ms（被刺激神经元为 0）
- 输入：Poisson 事件 `v += w_syn·f_poi = 68.75 mV`
- 突触：**环形延迟缓冲** `ring[D]`，`D = round(t_dly/dt) = 18`
- 传播：**稠密膜电位扫描 O(n) + 事件驱动只广播"已发放"神经元的出边**（作者实测稀疏模式反而更慢：20 s 模拟稠密 12.7 s vs 稀疏 19.2 s）
- 突触权重：`subcircuit.json` 用 Float32；页面内联版压缩成 Int16 + 比例（解码后逐位相同）
- 读出：`readRates(groups, windowSteps)` → 各组平均发放率（Hz）
- 附带实验接口：`setSilenced`（沉默）、`setWeightScale`/`setInhibScale`/`setGlutExcitatory`/`setShuffle`（论文式扰动）、`setDrive`（多路具名驱动，学习回路用）、`setOpto`（任意神经元光遗传驱动）

## 三、任务 B 的接口映射（这是本轮最有价值的产出）

### v3（5,563 神经元）的输入 / 输出组

| 类型 | 组名 | 神经元数 | 含义 |
|---|---|---|---|
| 输入 | `JO_left/right` | 229 / 204 | **Johnston's organ —— 听觉 / 风 / 触角位置** |
| 输入 | `TOUCH_left/right` | 150 / 155 | 机械感觉（触觉） |

| **输出** | `DNa01` / `DNa02` | 1+1 / 1+1 | 转向 |
| **输出** | `MDN` | 2+2 | 后退行走 |
| **输出** | `MN9` | 1+1 | 口器（取食） |
| 输出 | `aDN1` | 1+1 | 其他下行 |

### v5（15,055 神经元）额外增加

`ORN`（2,143，嗅觉受体神经元）、`OLFA`/`OLFR`（嗅觉投射）、`ISN`（内感受）、
`AUDIO`（370）、`PAM`/`PPL1`（多巴胺能，蘑菇体学习：Kenyon 细胞 5,177 + MBON 96 + DAN 331）。

### 与本项目 68 字节特征包的映射提案

| 板端特征 | → 脑输入 | 理由 |
|---|---|---|
| 低频段能量（<200 Hz） | `JO` | 约翰斯顿器就是听振动/风的，信号天然走这条 |
| 中 / 高频段（200–2000 Hz） | `JO` + `AUDIO`(v5) | 分层给不同频率通道 |
| 触摸标志位 | `TOUCH` | 直接对应 |
| IMU 加速度/角速度模长 | `TOUCH` 强度调制（或作本体感觉通道） | 暂时没有专门组，先做强度调制 |

| 脑输出 | → 板端动作 |
|---|---|
| `DNp01`（巨纤维） | 逃逸：马达满强度 + 屏幕红闪 |
| `DNa02` 左右差 | 转向（马达左右差速） |
| `MDN` | 后退 |
| `MN9` | 低功耗待机/取食模式 |

## 五、风险与限制（如实）

1. **许可证**：代码 GPL-3.0；**`results/` 下数据 CC BY-NC 4.0 → 禁止商用**。个人研究/自用没问题；
   一旦这个机器人涉及商业用途，数据部分必须先换掉或取得授权。
2. **成熟度**：仓库仅 3 周、19 star、单一作者、提交集中在 2026-09-15～09-22 一周内。
   但**底层科学是硬的**（FlyWire 2024 Nature + Shiu 2024 同行评议模型），且作者把
   **失败假设、负面结果、自查错误全写进了 `docs/log/report.md`**（"This repository records how many walls I drove it into."），
   工程诚实度很高。
3. **模型本身的已知局限**（作者自己列的）：Gomoku 上"真连接组并不比打乱的更好"；
   嗅觉是负结果；ISN 反了；靠触摸无法避墙 —— 这些都影响我们能用它做多"真"的行为。
4. **服务器出网**：直连 GitHub **不通**（`fetch-pack: unexpected disconnect`），
   **必须走镜像 `https://ghfast.top/https://github.com/...`**（已实测成功）。
   到 Google Cloud Storage 只有 ~20 KB/s，所以数据一律别走 GCS。

## 六、下一步（建议的执行顺序）

1. **打通最小闭环**：v3 子回路 + 我们的 68 字节特征 → `JO`/`TOUCH` → 读出 `DNp01`/`DNa02`
   → 打包下行指令。先在服务器上用回放的 UDP 数据跑通，不接板子。
2. **测闭环延迟**：任务 A 实测 RTT 66 ms + 50 ms 特征窗 ⇒ 地板约 130–180 ms。
   把脑步进 + 编码 + 读出的真实开销加进去，看还能不能守住 20 Hz（预期脑步进 <5 ms，可以忽略）。
3. **下行走板**：板端解析指令（任务 C 的依赖项）。
4. **再决定要不要上 v5**：v5 多了嗅觉 + 蘑菇体学习，但只有 1.0× 实时余量 ——
   若要留出安全边际，或把 UART/UDP I/O 放到第二核，或先停在 v3。
